# 1. 战斗资源循环：

1. 生命值HP：玩家受伤会填充血库（暂未实现），归零时玩家死亡
2. 血库BB：对弹药量的软性限制，装填时自动消耗以强化武器伤害，即使没有血液也能正常装填射击，只是伤害低一些
3. 武器弹药Ammo：伤害来源，击杀敌人掉落脏血瓶填充血库（不会治疗玩家），用强化血弹命中敌人能直接回复HP（吸血）


以此构成战斗时的资源循环，即使玩家受伤也会有奖励，失去的HP会以另一种形式回收，从而降低挫败感，也增加了天赋流派的开发深度
