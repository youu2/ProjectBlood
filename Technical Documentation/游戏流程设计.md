# 战斗资源循环

1. 生命值HP：玩家受伤会填充血库（暂未实现），归零时玩家死亡
2. 血库BB：对弹药量的软性限制，装填时自动消耗以强化武器伤害，即使没有血液也能正常装填射击，只是伤害低一些
3. 武器弹药Ammo：伤害来源，击杀敌人掉落脏血瓶填充血库（不会治疗玩家），用强化血弹命中敌人能直接回复HP（吸血）

以此构成战斗时的资源循环，即使玩家受伤也会有奖励，失去的HP会以另一种形式回收，从而降低挫败感，也增加了天赋流派的开发深度

### 全自动武器随机射击散布

全自动武器（AK、MP5）支持随机射击散布，模拟真实枪械的后坐力偏移效果。

**实现原理**：

- 每次射击时，在基础射击方向上随机偏移一个角度
- 偏移角度在 `[-spreadAngle/2, +spreadAngle/2]` 范围内均匀分布
- 散布角度为0表示精准射击（如半自动武器DE、AWP）

**实现代码**：

```csharp
protected Vector2 ApplySpread(Vector2 baseDirection)
{
    if (spreadAngle <= 0f)
        return baseDirection;
    
    float randomAngle = Random.Range(-spreadAngle / 2f, spreadAngle / 2f);
    Quaternion randomRotation = Quaternion.AngleAxis(randomAngle, Vector3.forward);
    return randomRotation * baseDirection;
}
```

**设计考量**：

- 增加AK和MP5,以及自动和半自动的差异
- 为新的天赋维度提供可能
- 半自动武器散布为0，保证每次射击的精准度

## 关卡地图布局配置（LevelsConfig）

关卡地图采用**树形结构**配置，通过 `LevelsConfig`为每一关预设多种布局, 替换原来在MapController中固定的关卡布局。

**核心类结构**：

| 类              | 职责     | 关键字段                                            |
| -------------- | ------ | ----------------------------------------------- |
| `LevelsConfig` | 关卡配置容器 | `difficulty` 难度等级                               |
| `RoomNode`     | 房间节点   | `roomType` 房间类型、`Children` 子房间列表                |
| `RoomType`     | 房间类型枚举 | InitRoom、NormalRoom、ChestRoom、ShopRoom、BossRoom |

**布局配置示例**：

```csharp
// Level1_1 示例布局
self.InitRoom
.NextRoom(RoomType.NormalRoom, branch =>
{
    branch.NextRoom(RoomType.NormalRoom)
          .NextRoom(RoomType.ChestRoom);
    branch.NextRoom(RoomType.ShopRoom, branch2 =>
    {
        branch2.NextRoom(RoomType.NormalRoom);
    });
    branch.NextRoom(RoomType.NormalRoom)
          .NextRoom(RoomType.BossRoom);
});
```

**特点**：

- 使用**链式调用**配置房间结构，代码可读性强
- 支持**分支结构**，同一房间可延伸多个后续房间
- 通过 `branch` 回调函数实现复杂布局
- 随机选择不同布局配置，增加重玩性

## 关卡难度曲线设计

1. 游戏分为3个大关，每个大关里面有3个小关，每个小关里面有数个房间，从1-1到1-3，然后是2-1到2-3，最后是3-1到3-3共计9个小关，每个X-3关卡都有一个Boss房间（还没实现）, 难度评级从0开始,每通过一小关就+1,特殊挑战关会临时突破现有的难度评级
2. 敌人强度评分: 每种怪物有一个难度分数, 配合关卡难度评级来控制每个房间的难度

## 房间难度控制

每个房间在进入后会根据难度评级生成一个房间难度分:

```csharp
var difficultyScore = UnityEngine.Random.Range(3, 6 + 1) + 2 * difficultyLevel;
```

**公式说明**：房间难度分 = 随机基础分(3-6) + 难度评级 × 2

**敌人波次配置: 根据当前难度评级生成**

```csharp
// 0-2为1-2波，3-5为1-3波，6-8为2-4波，9为3-5波
var waveCount = UnityEngine.Random.Range(Math.Max(1, difficultyLevel / 3), difficultyLevel / 3 + 2 + 1);
```

**公式说明**：波次数量 = 随机范围\[max(1, 难度评级÷3), 难度评级÷3+3]。难度评级每提升3级，最小波次+1，最大波次+1。

敌人类型配置: 房间难度分(difficultyScore)作为当前房间每波的难度目标(targetScore)

随机生成一个敌人评分, 根据评分来获取需要生成的敌人, 直到当前波次的敌人难度评分总和等于当前房间的难度评分. 这样不仅能维持原来的随机性,还能一定程度控制难度曲线. 

**难度控制参数**：

| 因素       | 影响                          |
| -------- | --------------------------- |
| **波次数量** | 每次进入房间根据难度分随机生成1-5波敌人       |
| **敌人类型** | 通过 `EnemyFactory` 按难度分数选择敌人 |
| **敌人数量** | 变化较大, 但是房间整体难度受难度评级限制       |

**敌人难度分数**：

| 敌人类型         | 强度评分   | 说明          |
| ------------ | ------ | ----------- |
| SlimeBlue    | 1      | 基础近战敌人      |
| AG           | 2      | 射击型敌人       |
| Compiler     | 3      | 辐射状射击敌人     |
| DemonI       | 4      | 激光攻击敌人      |
| Titan(开发中)   | 5      | 突进, 霰弹射击    |
| 对应的精英版本(开发中) | 基础分\*2 | 更疯狂的射击模式和数值 |

**波次生成流程**：

1. 玩家进入 NormalRoom 时触发战斗
2. 根据难度随机生成波次配置
3. 每波敌人按 `Enemy2GenList` 配置生成
4. 击败当前波次所有敌人后，刷新下一波
5. 所有波次完成后，房间通关，开启房门

**难度调节方向**：

- 调整波次和难度分算法
- 调整敌人强度评分
- 调整敌人属性：在 Prefab 或 `EnemyFactory` 中配置
