## 1. 小地图系统

### 1.1 功能概述

提供游戏世界可视化导航，实时显示玩家位置、已发现房间及状态连接。

### 1.2 核心配置

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `mapRange` | 2 | 控制视野范围，平衡信息展示与性能 |

### 1.3 房间状态

| 状态 | 说明 | 视觉反馈 |
| --- | --- | --- |
| `Unknown` | 未发现区域 | 隐藏 |
| `Init` | 已发现未进入 | 显示初始背景 |
| `Battle` / `Finished` / `Idle` | 已进入房间 | 当前房间高亮 |

### 1.4 核心逻辑

- **渲染机制**：每帧重建玩家周围 `mapRange` 范围内的已发现房间
- **发现机制**：进入房间时自动发现相邻有门连接的房间

## 2. 地图生成系统

### 2.1 功能概述

程序化生成关卡布局，包括房间节点树构建、BFS遍历生成、动态门布局及房间实例化。

### 2.2 核心数据结构

| 结构 | 用途 | 关键字段 |
| --- | --- | --- |
| `RoomNode` | 定义关卡结构树 | 房间类型、子节点列表 |
| `RoomGenerateConfig` | 存储生成配置 | `roomPosX`, `roomPosY`, `doorDirections` |
| `DynaGrid<T>` | 动态网格容器 | 二维坐标索引 |

### 2.3 生成流程

1. **构建节点树**：定义关卡结构（初始房间→普通房间→宝箱/Boss房间）
2. **BFS遍历**：广度优先搜索生成房间位置
3. **预测权重优化**：避免生成死路，提高地图连通性
4. **房间实例化**：根据配置生成实际房间对象
5. **走廊生成**：连接相邻房间

### 2.4 BFS算法核心

使用队列存储待生成房间，通过预测权重机制选择扩展方向，平衡随机性与连通性。

### 2.5 与其他模块交互

| 模块 | 交互方式 |
| --- | --- |
| 玩家系统 | 设置初始房间位置 |
| 敌人系统 | 传递敌人生成配置 |
| 小地图系统 | 提供房间网格数据 |

## 3. 武器吸血系统

### 3.1 功能概述

武器造成伤害时按比例吸血，通过生成纯血道具的方式恢复生命值，支持等级升级机制。

### 3.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `BaseLifestealPercent` | 1% | 基础吸血比例 |
| 每级加成 | +1% | 线性成长（暂时） |

### 3.3 机制流程

攻击 → 子弹携带吸血属性 → 击杀敌人 → 计算吸血总量 → 生成纯血道具 → 玩家拾取回血

### 3.4 关键设计

- **等级成长**：每级提升1%吸血比例，简单直观
- **子弹携带**：吸血属性通过子弹传递，支持差异化处理
- **道具化表现**：吸血效果以纯血道具形式呈现，增强视觉反馈和操作手感

> 架构设计详见：[PB 架构设计文档](file:///e:/unity/project/ProjectBlood/Technical%20Documentation/PB%20架构设计文档.md) 第3章「设计8：武器系统架构」

## 4. 护盾系统

### 4.1 功能概述

提供临时伤害抵挡能力，包含保护期机制（不消耗格挡次数）和格挡次数限制。

### 4.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `initialBlockCount` | 5次 | 基础格挡能力 |
| `gracePeriodDuration` | 5秒 | 激活后无敌缓冲期 |

### 4.3 机制流程

**激活**：拾取护盾 → 启动保护期 → 可抵挡伤害

**伤害处理**：承受伤害 → 扣除格挡次数 → 保护期内不检查碎裂 → 次数耗尽且非保护期时碎裂

> 设计决策详见：[PB 架构设计文档](file:///e:/unity/project/ProjectBlood/Technical%20Documentation/PB%20架构设计文档.md) 第3章「设计10：护盾系统」

## 5. 掉落物系统

### 5.1 功能概述

管理敌人掉落和房间奖励的收集逻辑，支持自动飞向玩家机制。

### 5.2 掉落物类型

| 类型 | 说明 | 是否自动收集 | 价格 |
| --- | --- | --- | --- |
| 经验球 | 提升武器等级 | 是 | - |
| 金币 | 商店消费货币 | 是 | - |
| 脏血 | 补充血库容量 | 是 | 5金币 |
| 护盾 | 提供临时伤害抵挡 | 否 | 10金币 |
| 纯血 | 恢复生命值（吸血产出） | 否 | 1金币 |

### 5.3 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `autoCollectOnRoomFinish` | true | 区分成长型道具和消耗品道具的拾取方式 |
| 特殊例外 | Shield | 护盾需手动拾取，增加策略性 |

### 5.4 机制流程

房间完成 → 普通掉落物自动飞向玩家 → 接触时触发收集效果

### 5.5 关键设计

- **自动收集**：减少玩家操作负担
- **抽象基类**：`DropItem` 定义通用行为和价格字段，子类实现具体效果
- **价格系统**：每个掉落物都有 price 字段，商店系统直接读取

## 7. 纯净之血系统（Pure Blood）

### 7.1 功能概述

武器吸血击杀敌人时，会从敌人身上爆出纯血道具，玩家拾取后恢复生命值。

### 7.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `ejectSpeed` | 7.5 | 初始飞射速度，实现吸血的视觉提示 |
| `flyDuration` | 0.15秒 | 飞射阶段持续时间 |
| `chaseSpeed` | 16 | 追踪阶段速度，保证能追上玩家 |
| `turnSmoothness` | 7 | 转向平滑度，太大会不自然 |

### 7.3 两阶段运动机制

**飞射阶段（Flying）**：
- 从敌人位置向随机方向弹出
- 带阻尼减速，模拟惯性效果
- 持续 0.15 秒后进入追踪阶段

**追踪阶段（Chasing）**：
- 平滑转向追踪玩家
- 速度逐渐加快到目标速度
- 碰到玩家就触发拾取

### 7.4 生成规则

- **触发条件**：武器吸血击杀敌人时生成
- **总治疗量** = 敌人总生命值 × 武器吸血百分比
- **数量计算**：1 + floor(总治疗量 / 5)，治疗量越大爆的血球越多
- **单个治疗量** = 总治疗量 / 数量，保证总和等于原吸血量

### 7.5 关键设计

- **视觉反馈**：多个小血球飞散再聚拢，比直接加血更有爽快感
- **独立音效**：有专门的拾取音效

## 8. 商店系统

### 8.1 功能概述

玩家可以在商店用金币购买道具，每个商店随机出售一件商品。

### 8.2 商品价格表

| 道具 | 价格 | 说明 |
| --- | --- | --- |
| 纯血（Pure Blood） | 1 金币 | 最便宜的回血道具 |
| 脏血（Dirty Blood） | 5 金币 | 补充 30 点血库容量 |
| 护盾（Shield） | 10 金币 | 5 次格挡 + 5 秒保护期 |

### 8.3 购买流程

1. 玩家靠近商店 → 显示价格提示
2. 按 F 键购买
3. 检查金币是否足够
   - 足够：扣除金币 → 生成道具 → 商品售罄
   - 不足：显示"Too expensive..."提示

### 8.4 商品池机制

- 每个商店有一个商品池（goodsPool）
- 游戏开始时从池中随机选一件作为本次出售的商品
- 买完就没了，不会补货

### 8.5 关键设计

- **价格复用**：价格定义在 DropItem 基类的 price 字段里，商店直接读取
- **售罄状态**：每件商品只能买一次，避免无限刷
- **购买反馈**：有专门的购买音效和文字提示
