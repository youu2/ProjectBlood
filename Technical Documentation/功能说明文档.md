## 1. 小地图系统

### 1.1 功能概述

提供游戏世界可视化导航，实时显示玩家位置、已发现房间及状态连接。

### 1.2 核心配置

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `mapRange` | 2 | 控制视野范围，平衡信息展示与性能 |

### 1.3 房间状态

| 状态 | 说明 | 视觉反馈 |
| --- | --- | --- |
| `Unknown` | 未发现区域 | 隐藏 |
| `Init` | 已发现未进入 | 显示初始背景 |
| `Battle` / `Finished` / `Idle` | 已进入房间 | 当前房间高亮 |

### 1.4 核心逻辑

- **渲染机制**：每帧重建玩家周围 `mapRange` 范围内的已发现房间
- **发现机制**：进入房间时自动发现相邻有门连接的房间

## 2. 地图生成系统

### 2.1 功能概述

程序化生成关卡布局，包括房间节点树构建、BFS遍历生成、动态门布局及房间实例化。

### 2.2 核心数据结构

| 结构 | 用途 | 关键字段 |
| --- | --- | --- |
| `RoomNode` | 定义关卡结构树 | 房间类型、子节点列表 |
| `RoomGenerateConfig` | 存储生成配置 | `roomPosX`, `roomPosY`, `doorDirections` |
| `DynaGrid<T>` | 动态网格容器 | 二维坐标索引 |

### 2.3 生成流程

1. **构建节点树**：定义关卡结构（初始房间→普通房间→宝箱/Boss房间）
2. **BFS遍历**：广度优先搜索生成房间位置
3. **预测权重优化**：避免生成死路，提高地图连通性
4. **房间实例化**：根据配置生成实际房间对象
5. **走廊生成**：连接相邻房间

### 2.4 BFS算法核心

使用队列存储待生成房间，通过预测权重机制选择扩展方向，平衡随机性与连通性。

### 2.5 与其他模块交互

| 模块 | 交互方式 |
| --- | --- |
| 玩家系统 | 设置初始房间位置 |
| 敌人系统 | 传递敌人生成配置 |
| 小地图系统 | 提供房间网格数据 |

## 3. 武器吸血系统

### 3.1 功能概述

武器造成伤害时按比例恢复生命值，支持等级升级机制。

### 3.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `BaseLifestealPercent` | 1% | 基础吸血比例 |
| 每级加成 | +1% | 线性成长，控制数值膨胀 |

### 3.3 机制流程

攻击 → 子弹携带吸血属性 → 命中敌人 → 计算并恢复生命值

### 3.4 关键设计

- **等级成长**：每级提升1%吸血比例，简单直观
- **子弹携带**：吸血属性通过子弹传递，支持差异化处理

> 架构设计详见：[PB 架构设计文档](file:///e:/unity/project/ProjectBlood/Technical%20Documentation/PB%20架构设计文档.md) 第3章「决策8：武器系统架构」

## 4. 护盾系统

### 4.1 功能概述

提供临时伤害抵挡能力，包含保护期机制（不消耗格挡次数）和格挡次数限制。

### 4.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `initialBlockCount` | 5次 | 基础格挡能力 |
| `gracePeriodDuration` | 5秒 | 激活后无敌缓冲期 |

### 4.3 机制流程

**激活**：拾取护盾 → 启动保护期 → 可抵挡伤害

**伤害处理**：承受伤害 → 扣除格挡次数 → 保护期内不检查碎裂 → 次数耗尽且非保护期时碎裂

> 设计决策详见：[PB 架构设计文档](file:///e:/unity/project/ProjectBlood/Technical%20Documentation/PB%20架构设计文档.md) 第3章「决策10：护盾系统」

## 5. 掉落物系统

### 5.1 功能概述

管理敌人掉落和房间奖励的收集逻辑，支持自动飞向玩家机制。

### 5.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `autoCollectOnRoomFinish` | true | 房间完成后自动收集，提升流畅度 |
| 特殊例外 | Shield | 护盾需手动拾取，增加策略性 |

### 5.3 机制流程

房间完成 → 掉落物自动飞向玩家 → 接触时触发收集效果

### 5.4 关键设计

- **自动收集**：减少玩家操作负担
- **抽象基类**：`DropItem` 定义通用行为，子类实现具体效果

## 6. 血库系统

### 6.1 功能概述

玩家的特殊资源系统，用于换弹强化和弹药管理。

### 6.2 核心参数

| 参数 | 默认值 | 设计意图 |
| --- | --- | --- |
| `MaxBloodAmount` | 100 | 最大脏血容量 |

### 6.3 资源循环

**获取**：玩家受伤自动补充 / 击杀敌人额外获取（血库低于阈值时）

**消耗**：换弹时消耗脏血强化武器

**转化**：强化武器击杀敌人可回复生命值
