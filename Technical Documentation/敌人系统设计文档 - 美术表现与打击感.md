## 1. 概述

敌人系统是 Project Blood 游戏战斗体验的核心组成部分。本文档详细记录了敌人系统在**美术表现**和**打击感**方面的重构设计，旨在提升玩家的战斗沉浸感和反馈体验。

***

## 2. 核心设计原则

### 2.1 打击感实现策略

| 要素       | 实现方式               | 效果目标     | 状态         |
| -------- | ------------------ | -------- | ---------- |
| **视觉反馈** | 血液飞溅、血迹残留、尸体飞散     | 直观显示伤害效果 | ✅ 已实现      |
| **音效反馈** | 受伤音效、攻击音效          | 增强听觉冲击力  | ✅ 已实现      |
| **物理反馈** | Collision碰撞产生的击退效果 | 增加真实感    | ✅ 已实现（待优化） |
| **数值反馈** | 伤害数字、暴击提示          | 明确战斗结果   | ❌ 未实现      |

> **设计说明**：原计划使用精灵颜色闪烁（红/白光）作为受击反馈，但该方案受限于敌人本身颜色（如红色敌人效果差），现已废弃。改为使用 FxManager 管理的血液飞溅和血迹残留特效。

### 2.2 状态机架构

敌人行为采用状态机模式管理，确保逻辑清晰且易于扩展：

```
[Idle] ←→ [Chase] ←→ [Wander] ←→ [Attack] ←→ [Death]
                                    ↓
                              [Charge/Aim]
```

## 3. 美术表现系统

### 3.1 受伤视觉反馈

> **重构说明**：原实现使用精灵颜色闪烁（红/白光）作为受击反馈，但该方案受限于敌人本身颜色（如红色敌人效果差），现已废弃。改用 FxManager 管理的血液飞溅和血迹残留特效。

#### 3.1.1 血液飞溅系统

**实现位置**: `FxManager.cs:39-58`

**核心流程**:

1. 实例化血迹精灵
2. 随机角度和距离计算飞溅轨迹
3. 使用缓动函数实现自然的飞溅动画

```csharp
public static void DrawBlood(Vector2 originPos, SpriteRenderer bloodSource)
{
    var blood = bloodSource.Instantiate()
        .Position2D(originPos)
        .EulerAnglesZ(Random.Range(0, 360f))
        .LocalScale(0.1f)
        .Show();

    var angle = Random.Range(0, 360);
    var radius = Random.Range(0.2f, 1.5f);
    var movePos = angle.AngleToDirection2D() * radius;
    var scaleTo = Random.Range(0.2f, 3.0f);
    
    ActionKit.Lerp(0, 1, Random.Range(0.1f, 0.3f), (p) =>
    {
        p = EaseUtility.InCubic(0, 1, p); // 使用缓动函数
        blood.Position2D(originPos + movePos * p);
        blood.LocalScale(scaleTo * p);
    }).StartCurrentScene();
}
```

**设计参数**:

| 参数   | 范围           | 说明      |
| ---- | ------------ | ------- |
| 飞溅角度 | 0° \~ 360°   | 全方位随机分布 |
| 飞溅距离 | 0.2f \~ 1.5f | 形成层次感   |
| 缩放大小 | 0.2f \~ 3.0f | 模拟远近效果  |
| 动画时长 | 0.1f \~ 0.3f | 快速完成不拖沓 |

```csharp
public void TakeDamage(float Damage, Vector2 HitDir)
{
    if (isDying) return;

```

#### 3.1.4 碰撞与击退机制

**重构变更**：将子弹与敌人的碰撞检测从 `Trigger` 改为 `Collision`

| 碰撞类型          | 特点            | 适用场景      |
| ------------- | ------------- | --------- |
| **Trigger**   | 无物理碰撞响应，仅触发事件 | 检测进入/离开区域 |
| **Collision** | 有物理碰撞响应，产生推力  | 需要物理交互的战斗 |

**设计说明**：

- 使用 Collision 碰撞后，敌人会被子弹物理击退
- 击退效果由 Unity 物理引擎自动计算，当前不可控
- **优化方向**：后续计划实现自定义击退逻辑，控制击退距离和持续时间

### 3.2 死亡动画系统

> **重构说明**：原实现使用 `DeathSequence()` 协程实现死亡前闪烁效果（红/白光交替），但该方案受限于敌人颜色，现已废弃。改用 `ActionKit.Lerp` 实现尸体飞散动画。

#### 3.2.1 尸体飞散效果

**实现位置**: `Enemy.cs:104-135`

**设计流程**:

1. 从房间敌人列表中移除
2. 禁用所有碰撞体（防止继续碰撞）
3. 实例化尸体精灵（随机翻转增加自然感）
4. 使用 ActionKit.Lerp 实现尸体沿受击方向飞出动画
5. 延迟销毁敌人对象

```csharp
protected virtual void Death(Vector2 HitDir)
{
    // 从房间移除
    if (Room != null)
        Room.GetEnemies().Remove(this);
    
    isDying = true;
    moveSpeed = 0f;
    
    // 禁用碰撞体
    if (allColliders != null)
        foreach (var c in allColliders) if (c) c.enabled = false;

    // 实例化尸体并随机翻转
    var dieBody = body.Instantiate()
        .Self(self => { self.flipX = RandomUtility.Choose(true, false); })
        .Show();

    // 尸体飞出动画（使用 ActionKit 而非协程）
    var dieBodyOriginPos = transform.Position2D();
    var dieBodyMoveToDistance = Random.Range(0.5f, 1.3f);
    
    ActionKit.Lerp(0, 1, 0.3f, (p) =>
    {
        dieBody.transform.Position2D(Vector2.Lerp(dieBodyOriginPos, 
            dieBodyOriginPos + dieBodyMoveToDistance * HitDir, p));
    }).StartCurrentScene();

    Global.currentNum.Value -= 1;
    this.DestroyGameObjGracefully();
}
```

**设计参数**:

| 参数   | 范围           | 说明        |
| ---- | ------------ | --------- |
| 飞出距离 | 0.5f \~ 1.3f | 随机变化增加自然感 |
| 动画时长 | 0.3秒         | 快速且有冲击力   |
| 翻转概率 | 50%          | 尸体朝向随机    |

**设计特点**:

- **尸体残留**：死亡时会留下尸体精灵，增加战斗痕迹
- **击飞效果**：尸体沿受击方向飞出，增强打击感
- **ActionKit 实现**：使用 QFramework 的 ActionKit 替代传统协程，代码更简洁

#### 3.3.1 蓄力指示器

**实现位置**: `LaserEnemy.cs:281-304`

**设计特点**:

- 使用 `LineRenderer` 渲染激光
- 蓄力阶段使用专用材质（chargeMaterial）
- 激光宽度随蓄力进度递增

```csharp
void ShowChargeIndicator()
{
    if (laserLines.Count == 0) return;

    Vector3 startPos = transform.position + transform.right * laserStartOffset;
    float width = laserWidth * chargeProgress;

    for (int i = 0; i < laserLines.Count; i++)
    {
        LineRenderer lr = laserLines[i];
        lr.enabled = true;
        if (chargeMaterial != null)
            lr.material = chargeMaterial;
        lr.startWidth = width;
        lr.endWidth = width;

        float angleOffset = GetLaserAngleOffset(i);
        Vector3 laserDir = RotateVector(transform.right, angleOffset);
        lr.SetPosition(0, startPos);
        lr.SetPosition(1, startPos + laserDir * attackRange);
    }
}
```

```csharp
void UpdateFireFlash()
{
    if (fireFlashRenderer == null || fireFlashSprites == null || fireFlashSprites.Length == 0)
        return;

    frameCounter++;
    if (frameCounter >= framesPerSprite)
    {
        frameCounter = 0;
        currentSpriteIndex = (currentSpriteIndex + 1) % fireFlashSprites.Length;
        fireFlashRenderer.sprite = fireFlashSprites[currentSpriteIndex];
    }
}
```

#### 3.3.3 激光淡出效果

**实现位置**: `LaserEnemy.cs:470-497`

```csharp
IEnumerator FadeOutLaser()
{
    float duration = 0.2f;
    float elapsed = 0f;
    float startWidth = laserWidth;

    while (elapsed < duration)
    {
        float t = elapsed / duration;
        float width = Mathf.Lerp(startWidth, 0f, t);

        foreach (LineRenderer lr in laserLines)
        {
            if (lr != null)
            {
                lr.startWidth = width;
                lr.endWidth = width;
            }
        }
        elapsed += Time.deltaTime;
        yield return null;
    }
    HideLaser();
}
```

## 6. 射击敌人散射系统

### 6.1 散射弹丸配置

**实现位置**: `ShootingEnemy.cs`

| 参数                 | 类型    | 默认值   | 说明             |
| ------------------ | ----- | ----- | -------------- |
| scatterBulletCount | int   | 3     | 每次射击发射的弹丸数     |
| scatterAngle       | float | 45°   | 总散布角度范围        |
| useRandomScatter   | bool  | false | 是否随机散布（否则均匀分布） |

### 6.2 角度计算算法

**均匀分布**:

```csharp
protected virtual float CalculateBulletAngle(int index)
{
    if (useRandomScatter)
        return Random.Range(-scatterAngle / 2f, scatterAngle / 2f);
    else
    {
        if (scatterBulletCount == 1) return 0f;
        return (-scatterAngle / 2f) + (scatterAngle / (scatterBulletCount - 1f)) * index;
    }
}
```

**方向计算**:

```csharp
protected virtual Vector3 CalculateBulletDirection(Vector3 baseDirection, float angleDegrees)
{
    float radian = angleDegrees * Mathf.Deg2Rad;
    return new Vector3(
        baseDirection.x * Mathf.Cos(radian) - baseDirection.y * Mathf.Sin(radian),
        baseDirection.x * Mathf.Sin(radian) + baseDirection.y * Mathf.Cos(radian),
        0
    ).normalized;
}
```

## 7. 状态机实现

### 7.1 基础敌人状态

| 状态         | 行为描述     | 触发条件       |
| ---------- | -------- | ---------- |
| **Idle**   | 待机不动     | 玩家不存在      |
| **Chase**  | 追击玩家     | 玩家进入攻击范围外  |
| **Wander** | 垂直玩家方向移动 | 玩家进入追击范围   |
| **Shoot**  | 原地射击     | Wander时间结束 |

### 7.2 激光敌人扩展状态

| 状态       | 行为描述 | 触发条件       |
| -------- | ---- | ---------- |
| **Aim**  | 瞄准玩家 | Wander时间结束 |
| **Fire** | 发射激光 | 蓄力完成       |

### 7.3 状态转换流程

```
Chase → Wander → Aim → Fire → Chase
                        ↑
                  蓄力完成
```
