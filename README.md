# 项目名称
- Blood(暂定)

---

## 游戏简介
这是一款结合 **类吸血鬼幸存者自动战斗** 与 **回合制卡牌构筑** 的 Roguelike 卡牌动作游戏。  
玩家将在每个回合开始前抽取并打出卡牌，构建本回合的战斗能力，然后进入自动战斗阶段对抗成波来袭的敌人，直至到达目标地点。  
在战斗间隙，玩家可进入商店、安全屋或触发随机事件，不断强化自身，挑战更高难度的敌人或Boss。

---

## 核心玩法
1. **回合制构筑 + 实时自动战斗**  
   - 回合开始：抽卡 → 出牌 → 装备技能  
   - 战斗阶段：自动攻击 + 玩家小技能手动释放  
   - 抵达目标点：触发精英怪潮并清场

2. **怪物推进方向有策略性**  
   - 大多数敌人从单一方向来袭，便于资源集中获取  
   - 特殊波次会四面包围，制造紧迫感与挑战性

3. **技能持续 & 升级机制**  
   - 卡牌提供的能力有持续回合数  
   - 同名卡牌可刷新持续时间并提升技能等级  
   - 能力到期后保留等级，等待下次激活

4. **肉鸽式成长**  
   - 战斗掉落、商店购买、随机事件获取道具  
   - 道具能强化卡牌、小技能或改变战斗规则

## 系统构成

### 1. 卡牌系统
- **攻击卡**：火球术、闪电链、太刀（自动攻击，仅持续数回合）
- **控制卡**：冰墙、陷阱、定身术（自动部署类似攻击卡）
- **增益卡**：护盾、加速光环、召唤守卫
- **机制卡**：卡牌生效时间延长、额外触发、技能进化

### 2. 小技能系统
- 局外选择 2 个可主动释放的小技能  
- 战斗中有冷却时间，适合打断怪物攻势或救急

### 3. 道具系统（提供永久增益，区别于卡牌）
- 被动效果（攻速提升、范围扩大、额外金币）  
- 卡牌机制强化（技能过期触发新技能）  
- 小技能辅助（冷却缩短、额外释放次数）

### 4. 怪物系统
- 普通怪：数量多、血少
- 精英怪：特殊光环或技能
- 中立怪：不主动攻击，掉落稀有资源

---

## 随机关卡与事件
- **限时挑战**：时间内清怪可获稀有奖励  
- **挑战宝箱**：触发怪潮，存活即可开箱  
- **精英连战**：多波精英怪，奖励翻倍  
- **恶魔交易**：用现有资源状态换取强力卡

---

## 游戏循环示意
- [抽卡构筑] → [战斗推进] → [目标点精英战] → [商店/事件/Boss] → [下一回合]


## 开发目标
- 节奏紧凑、策略与割草爽感兼备的动作卡牌游戏
- 解决幸存者类 [掉落收集不便] [无目标] [无法中途更换流派]的体验问题
- 通过卡牌机制与道具系统创造高可玩性的构筑乐趣


## 开发进度

### 经验值系统（EXP）
- 击杀任意怪物获得 **1 点 EXP**（后续可以根据怪物强度调整为不同数值）。
- 当前 EXP 通过全局变量记录（例如 `Global.Exp`），方便 UI 和升级系统监听。

### 等级系统（Level）
- 每 **5 点 EXP 升一级**，升级时触发一次「升级事件」：
  - 重置本级已获得的 EXP 计数（例如从 5/5 变成 0/5）。
  - 弹出升级选单 / 卡牌选择界面（预留接口）。
- 等级同样通过全局变量记录（例如 `Global.Level`），用于数值成长和解锁内容。

### 关卡 / 波次节奏设计
- **时间单位**：每 **30 秒** 为一波怪（Wave）。
- 每一波有以下限制参数（随波次自动成长）：
  - `TotalSpawnLimit`：本波最多生成的怪物总数。
  - `MaxActiveEnemies`：场上同时存在的怪物上限。
  - `SingleSpawnCount`：单次刷怪时生成的怪物数量。
- 生成规则：
  - 计时器开始后，按照固定间隔刷怪，直到「本波生成总数」或「场上存活数量」达到任一上限就停止生成。
  - 如果玩家提前击杀掉本波所有已生成怪物（场上清空），会**立即跳转到下一波**，不必等待 30 秒结束。
- 难度成长：
  - 随波次提升，`TotalSpawnLimit`、`MaxActiveEnemies`、`SingleSpawnCount` 会按照配置的增量线性增长，保证敌人密度和压力逐步提升。

### 波次系统：怪物池逻辑（Enemy Pool）
- **全局怪物池（Total Pool）**
  - 包含游戏中所有怪物种类，每个怪物带有一个「强度值（Strength）」。
  - 启动时按强度从低到高排序，作为敌人解锁顺序的基础。
- **当前怪物池（Current Pool）**
  - 实际参与刷怪的怪物列表，从全局怪物池中选出。
  - 当前怪物池最多包含 **3 种怪物**。
  - 敌人生成时只会从当前怪物池中随机选择怪物类型进行生成。
- **怪物池更新规则**
  - 每经过固定波数（例如 **每 5 波**），更新一次当前怪物池：
    1. 从全局怪物池中取出**尚未解锁的下一只更强怪物**。
    2. 若当前怪物池未满（少于 3 种），则直接加入当前池。
    3. 若当前怪物池已满 3 种，则先移除当前池中**最弱的怪物**，再将新的更强怪加入。
  - 当全局怪物池中的怪物全部解锁后，将不再更新，只通过数值成长继续提升难度。
- **优点**
  - 不再需要为每一波手动配置怪物列表，波次系统会根据全局怪物池和强度值**自动“换怪升级”**。
  - 难度节奏更加平滑：前期以低强度小怪为主，之后逐步替换成更强怪物，保持玩家压力增长但不突兀。

### 掉落物与传承点（Legacy Point）

#### 掉落物体系：局内 vs 局外

- **局内资源**
  - 金币（Gold）：仅在当前局内使用，用于商店购买卡牌 / 道具等。
  - 经验值（EXP）：用于本局内升级，解锁/选择新能力或强化现有能力。
- **局外资源**
  - 传承点（Legacy Point）：用于**局外永久升级**，例如解锁新卡池、提升初始属性、解锁被动等。  
  - 特点：
    - 在多局游玩之间**持续累积**，不会因为重开而清零。

#### 传承点获取时机（设计）

- **基础设计目标**
  - 传承点主要来源于一次「完整游玩循环」的表现，而不是单个小掉落。
  - 鼓励玩家「多打一局」而不是在一局内死磕刷资源。
- **规划中的获取途径**
  - 【已确定】局内结算时获取：
    - 玩家死亡 / 通关时，根据本局表现结算传承点。
    - 公式预留：可按「已完成波次数量」「击杀怪物数量」「精英怪数量」「通关/失败状态」等综合计算。
  - 【可选扩展】特殊事件奖励：
    - 稀有事件、挑战宝箱、精英连战的额外奖励中，少量附带传承点。
  - 【可选扩展】里程碑奖励：
    - 首次打到某个关卡 / 首次击杀某个 Boss 时，发放一次性传承点奖励。

#### 传承点数据结构与持久化

- **全局变量**
  - 在 `Global` 类中增加：
    - `Global.LegacyPoint : BindableProperty<int>` 用于全局记录当前传承点数值。
  - 好处：
    - UI 可以直接监听 `Global.LegacyPoint`，实时刷新显示。
    - 结算逻辑可以方便地累加 / 扣减传承点。

- **存档与加载（PlayerPrefs）**
  - 【已实现】
    - 游戏启动时从本地存档中读取：
      - `Global.LegacyPoint.Value = PlayerPrefs.GetInt("LegacyPoint", 0);`
    - 在 UI / 管理器中注册监听，在数值变化时自动写回：
    - 这样可以保证：
      - 玩家每次获得 / 消耗传承点时，**自动保存**到本地。
      - UI 在场景加载后能立刻显示当前最新的传承点数值。

#### 局外升级：消耗传承点（预留）

- **目标**
  - 使用传承点在「局外升级界面」中进行长期成长：
    - 提升初始生命值 / 攻击力 / 移动速度等基础属性。
    - 解锁新的卡牌池 / 道具 / 小技能。
    - 解锁局内新机制（例如更高的起始波次、更高的商店刷新品质等）。
- **系统状态**
  - 【已规划】
    - 传承点作为所有局外升级的唯一货币。
    - 局外升级界面预留数据结构与按钮交互（尚未实现）。
  - 【待实现】
    - 升级树 / 升级节点的具体内容与数值。
    - 消耗传承点后的存档更新与 UI 刷新逻辑。
