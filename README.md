# Project Blood

2D 像素风俯视角 Roguelike 射击游戏，Unity / C# 独立开发。

> 个人项目，持续开发中。2025.12 起玩法方向由「类吸血鬼幸存者」转向「类枪牢」，核心系统近乎重写；仓库中保留少量历史文档，已在文首标注状态。

## 玩法支柱

- **血库资源循环**：受伤将生命值转化为「脏血」，换弹消耗脏血强化弹丸，强化状态击杀回复生命。资源循环被打破时，袖剑击杀可回填脏血并提供兜底恢复。
- **无前后摇切枪**：切换武器重置攻击间隔，用切枪打断单枪射击间隔形成伪多线输出；半自动武器的成长只投放攻速与弹匣，增伤留给全自动，避免切枪频率把增伤成倍兑现。
- **血印构筑**：以「触发条件 / 结算效果 / 结束条件 / 门控」四要素组合的构筑系统，支持被动与主动（1–4 键开关）两类血印。
- **袖剑处决**：瞬移穿墙、慢动作、无敌帧与处决奖励，兼具爆发、位移与资源补救。
- **程序化地牢**：BFS + 方向权重生成随机连通布局，9 关 3 章，每关 3 种布局；含 Chest / Shop / Boss 房间与两阶段 Boss。

## 架构要点

- **数据驱动**：武器、敌人、升级卡、血印、技能均以 ScriptableObject 配置；新增内容以配置为主，尽量零代码。
- **分层继承**：`WeaponBase → AutomaticWeapon / SemiAutomaticWeapon`；`EnemyBase → Enemy → ShootingEnemy / LaserEnemy / MeleeEnemy`，`BossBase → TitanBoss`。
- **事件驱动**：`BloodSigilState` 通过开火 / 技能 / 切枪 / 受伤 / 击杀 / 血量变化事件分发，无每帧全量轮询。
- **对象池与集中管理**：子弹、弹壳、血液与尸体特效由对象池 / `FxManager` 统一管理，场景切换集中清理。
- **共享逻辑抽取**：散射数学（`SpreadMath`）、即时命中判定（`BlastAttackExecutor` / `InstantHitResolver`）收敛重复实现。

## 关键性能优化

| 指标           | 优化前                 | 优化后                |
| :----------- | :------------------ | :----------------- |
| 每帧 GC        | 峰值 240KB / 常态 200KB | 峰值 10KB / 常态 0.5KB |
| 复杂场景 Batches | 1000+               | 200 以内             |
| 帧率           | 30\~60              | 150\~200           |
| UI Batches   | 约 10                | 3                  |
| 光源合批         | 3                   | 1                  |

主要手段：收敛光源影响范围、合并双光源职责、小地图由每帧重绘改为事件驱动、统一 Sprite Atlas / TMP 字体 / UI 层级。

## 设计验证：轮切 DPS

固定获取顺序，10000 血木桩，近距离、快速切枪，记录击杀时间：

| 配置                 | 击杀时间 | DPS   |
| :----------------- | :--- | :---- |
| 2 把（1 半自动 + 1 全自动） | 83s  | 120.5 |
| 3 把（+1 半自动）        | 45s  | 222.2 |
| 4 把（+1 全自动）        | 42s  | 238.1 |
| 5 把（+1 半自动）        | 24s  | 416.7 |
| 6 把（+1 全自动）        | 22s  | 454.5 |

每加入 1 把半自动 DPS 提升 75\~84%，每加入 1 把全自动仅 7\~9%。单持 DPS 相近的两对武器（ShotGun/AK、AWP/Laser）轮切边际贡献相差 4.7\~6.4 倍，说明收益来自射击间隔而非单发伤害。

## 运行

1. 使用 Unity Hub 安装 **Unity 2022.3.62f3**。
2. 打开本仓库根目录（Unity 会自动导入依赖与 QFramework）。
3. 打开 `Assets/Scenes/GameStart.unity`，点击 Play。
4. 若音频无声，请确认 FMOD 插件与 bank 已正确导入。

## 素材与 AI 使用说明

- **像素美术**：95%以上由作者绘制。
- **音乐**：由 Suno AI 生成，作者进行筛选、剪辑与游戏内编排。
- **音效**：使用 Reaper 剪辑与合成；原型阶段包含仅用于本地验证的临时占位素材，未用于商业用途，公开发布前将替换为授权素材。
- **代码**：部分系统在 AI 辅助下完成（生成、重构与注释），设计决策、调试与验证由作者完成。
