# 项目名称
- Blood(暂定)

---

## 游戏简介
这是一款结合 **类吸血鬼幸存者自动战斗** 与 **回合制卡牌构筑** 的 Roguelike 卡牌动作游戏。  
玩家将在每个回合开始前抽取并打出卡牌，构建本回合的战斗能力，然后进入自动战斗阶段对抗成波来袭的敌人，直至到达目标地点。  
在战斗间隙，玩家可进入商店、安全屋或触发随机事件，不断强化自身，挑战更高难度的敌人或Boss。

---

## 核心玩法
1. **回合制构筑 + 实时自动战斗**  
   - 回合开始：抽卡 → 出牌 → 装备技能  
   - 战斗阶段：自动攻击 + 玩家小技能手动释放  
   - 抵达目标点：触发精英怪潮并清场

2. **怪物推进方向有策略性**  
   - 大多数敌人从单一方向来袭，便于资源集中获取  
   - 特殊波次会四面包围，制造紧迫感与挑战性

3. **技能持续 & 升级机制**  
   - 卡牌提供的能力有持续回合数  
   - 同名卡牌可刷新持续时间并提升技能等级  
   - 能力到期后保留等级，等待下次激活

4. **肉鸽式成长**  
   - 战斗掉落、商店购买、随机事件获取道具  
   - 道具能强化卡牌、小技能或改变战斗规则

---

## 系统构成

### 1. 卡牌系统
- **攻击卡**：火球术、闪电链、太刀（自动攻击，仅持续数回合）
- **控制卡**：冰墙、陷阱、定身术（自动部署类似攻击卡）
- **增益卡**：护盾、加速光环、召唤守卫
- **机制卡**：卡牌生效时间延长、额外触发、技能进化

### 2. 小技能系统
- 局外选择 2 个可主动释放的小技能  
- 战斗中有冷却时间，适合打断怪物攻势或救急

### 3. 道具系统（提供永久增益，区别于卡牌）
- 被动效果（攻速提升、范围扩大、额外金币）  
- 卡牌机制强化（技能过期触发新技能）  
- 小技能辅助（冷却缩短、额外释放次数）

### 4. 怪物系统
- 普通怪：数量多、血少
- 精英怪：特殊光环或技能
- 中立怪：不主动攻击，掉落稀有资源

---

## 随机关卡与事件
- **限时挑战**：时间内清怪可获稀有奖励  
- **挑战宝箱**：触发怪潮，存活即可开箱  
- **精英连战**：多波精英怪，奖励翻倍  
- **恶魔交易**：用现有资源状态换取强力卡

---

## 游戏循环示意
- [抽卡构筑] → [战斗推进] → [目标点精英战] → [商店/事件/Boss] → [下一回合]


## 开发目标
- 节奏紧凑、策略与割草爽感兼备的动作卡牌游戏
- 解决幸存者类 [掉落收集不便] [无目标] [无法中途更换流派]的体验问题
- 通过卡牌机制与道具系统创造高可玩性的构筑乐趣
