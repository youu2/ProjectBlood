# 袖剑（处决技能）技术设计文档

> 状态：四轮问答完成，代码已实现（阶段 A–E 完成），待 Unity Editor 资产接线与 Play Mode 联调
> 最后更新：第四轮收尾确认已回填（无目标反馈、命中帧驱动、近战距离初值、Boss DirtyBlood 保留）
> 灵感来源：《刺客信条》袖剑处决

## 1. 概述

袖剑是玩家的**第二个默认主动技能**，F 键释放，基础充能间隔约 8 秒（1 层充能，等同传统 CD）。

它同时承担四个功能定位：

1. **残血处决**：技能范围内存在濒死敌人时，自动锁定最近的濒死敌人，位移到其身后一击必杀；
2. **风险换资源**：被袖剑杀死的敌人为血库回血，并以"袖剑默认强化吸血"的方式产出 PureBlood；
3. **战术位移**：朝目标高速冲刺，可借敌人为"穿墙锚点"越过墙体，全过程无敌帧；
4. **慢动作演出**：按下 F 当帧 timeScale 降为 0.2，真实时间约 0.5 秒。

**关键约束（第三轮简化）：范围内没有敌人时袖剑无法释放**（不触发演出、不耗 CD）。袖剑不是随时可用的通用位移，而是必须以敌人为锚点的突进。攻击为**单体、纯演出**：只对锁定目标造成伤害，不存在范围判定。

设计目的是配合"敌人不再掉落 DirtyBlood、受伤反而增加血库"的资源循环，鼓励玩家主动进行高风险贴脸操作。

## 2. 已确认的设计决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 目标选择 | **自动选择，不可手动指定**。360° 圆形范围；优先选范围内**距离玩家最近的濒死敌人**，否则选范围内最近的普通敌人。**包含墙后敌人** |
| 2 | "背后"的定义 | 沿"玩家→目标"方向高速移动，越过敌人后再多移动一个固定偏移量（约 1 单位，序列化），落点即敌人身后。不读取敌人朝向，也不处理与敌人身体的重叠 |
| 3 | 无目标时（第三轮简化） | **袖剑无法释放**：F 键无任何效果，不播动画、不进慢动作、**不消耗 CD**。不再有空放冲刺、不再有矩形 AOE |
| 4 | 位移途中目标死亡 | 继续移动到预定落点，**不触发刺击、不造成伤害，到达后立即结束技能、恢复 timeScale、刷新 CD**（高熟练度玩家的无损无后摇位移技巧） |
| 5 | 架构方式 | **混合式**：目标搜索、单体伤害等做成可复用的通用 SkillEffect；处决条件判定/CD 刷新等袖剑专属逻辑放专属部分 |
| 6 | 可调性 | 所有数值第一版即做成 SerializeField；配 Gizmos 绘制范围圈、目标连线、预定/修正落点 |
| 7 | 击杀方式 | 对敌人调用 `TakeDamage(伤害)`，**走现有死亡管线**（血印击杀通知、掉落、房间计数、尸体特效等全部自然生效） |
| 8 | Boss / 精英 | **不可处决，只能刺击**。通过 EnemyBase 上的序列化开关 `canBeExecuted`（默认 true，BossBase/Boss 预制体为 false）实现，未来血印可改写此标志 |
| 9 | 濒死阈值 | 使用**百分比**（当前血量/最大血量 ≤ 阈值）。未来可被升级系统强化，本期搁置 |
| 10 | 无敌敌人（未来） | 处决可以正常触发并造成"足够大的伤害"，但无敌敌人不受任何伤害——表现照常、无击杀、无收益、不刷新 CD |
| 11 | 无敌帧 | 袖剑**全过程（位移 + 刺击）**无敌，复用翻滚的切层无敌方案；定位与翻滚不重叠 |
| 12 | 连锁处决 | **不加限制**。当前武器系统缺乏高效范围伤害，连锁处决是应得的爽点；未来范围血印凑齐困难，若凑齐即可爽快连锁 |
| 13 | 血库已满 | 处决回血直接溢出，不转化为其他收益 |
| 14 | 收益规则 | **只要锁定敌人是被袖剑杀死的**（处决伤害或刺击伤害），就加血库、产出 PureBlood、刷新 CD。未造成击杀不给任何资源。血库与生命值是两种独立资源 |
| 15 | 吸血 | 袖剑默认视为强化状态，**吸血不消耗血库资源**；击杀时 `Global.GeneratePureBlood(敌人, 敌人maxHealth × 袖剑吸血比例)`，吸血比例为袖剑独立变量 |
| 16 | 伤害加成 | 刺击伤害吃**全局增伤**和**技能增伤（新概念，本期只预留）**，**不吃武器增伤、不吃按武器类型聚合的血印增伤**；处决伤害为独立大数值常量，不吃任何加成 |
| 17 | 慢动作 | 按下 F **当帧** timeScale = **0.2**（已最终确认）；袖剑自身逻辑按真实时间（unscaled）驱动，真实时长约 0.5 秒 |
| 18 | 输入锁定 | 袖剑期间**锁定全部输入**：移动、开火、换弹、切枪、翻滚/技能、瞄准旋转 |
| 19 | 伤害方式（第三轮简化） | **只对锁定目标单体结算，无范围判定、无矩形框**；刺击特效是纯演出，伤害在刺击瞬间对锁定目标施加 |
| 20 | 濒死提示 | **所有现存濒死敌人头顶都显示**文本（不限距离），默认"危"，Inspector 可调，仅控制显隐。显隐只在 TakeDamage 时判定，不做每帧轮询 |
| 21 | 红色 AimMark | 新增红色 AimMark（现有 AimMark 被自动瞄准占用）挂在玩家身上，只标记**技能范围内最近的一个**濒死敌人，无目标时隐藏 |
| 22 | 刺击表现 | 玩家身上挂**独立于 Player Animator 的刺击特效 Animator**（帧动画，UnscaledTime 更新），玩家自身动作不改；第一版预留动画 trigger |
| 23 | 落点修正 | 落点做墙体检测并沿墙修正；与敌人重叠不处理；玩家朝向/武器朝向不处理 |
| 24 | 键位 | 删除当前无意义的 Q 键（"技能2"），袖剑绑定 **F 键**，是第二个技能（翻滚仍为 Space） |
| 25 | 射击敌人改造 | 参照 LaserEnemy 增加**序列化转向速度限制**（现为瞬时转向），防止绕身后立刻被贴脸连射 |
| 26 | 近战敌人改造 | 增加约 **0.3 秒攻击前摇**；前摇结束时**重新检测距离与视线，脱离范围则空挥**；追击转攻击距离与伤害结算范围分别做成 Inspector 可调字段，且**结算范围略大于触发距离**；前摇期间头顶显示**红色"!"** |
| 27 | 暂停冲突 | 袖剑真实 0.5 秒期间**屏蔽 Esc 暂停**；所有退出路径必须恢复 timeScale 与玩家层 |
| 28 | 初始朝向 | 无目标不能释放后，最后移动方向不再参与袖剑逻辑（翻滚仍使用） |

## 3. 技能行为流程

### 3.1 释放瞬间（按下 F）

```
按下 F
  ├─ 充能/状态检查（复用 SkillManager 现有门控）
  ├─ 在当前房间敌人列表中搜索：
  │    1. 收集技能半径内的全部敌人（360°，不做墙体遮挡剔除）
  │    2. 其中筛选"濒死且 canBeExecuted"的敌人 → 取距玩家最近者
  │    3. 若无濒死目标 → 取范围内最近敌人（含 Boss）
  ├─ 无任何目标 → 技能不释放，无任何消耗与表现（相当于按键无效）
  └─ 有目标 → 当帧 timeScale=0.2、进入袖剑状态（锁输入）、开启无敌帧，进入冲刺
```

- 濒死判定：`currentHealth / maxHealth <= 处决阈值百分比` 且 `canBeExecuted == true`；
- 目标类型（处决/刺击）在出手时锁定，**冲刺途中不会因血量变化切换**；
- 目标搜索范围限定在**当前房间** `Global.currentRoom.GetEnemies()`（避免选中其他房间敌人穿越房门）。

### 3.2 冲刺与结算

1. 位移方向 = （目标位置 − 玩家位置）.normalized；
2. 预定落点 = 目标位置 + 位移方向 × 落点偏移量（越过敌人约 1 单位）；
3. 按真实时间高速移动到预定落点（**直接改位置，允许穿墙**），逐帧检测目标是否存活；
4. 落点做墙体检测与沿墙修正；
5. **目标在冲刺途中死亡/引用失效**：到达落点后**立即**恢复 timeScale、解除状态、刷新 CD，不播刺击、不造伤害；
6. 目标存活，到达后触发刺击特效（纯演出），在刺击瞬间对**锁定目标单体**结算：
   - 出手时锁定为濒死且 `canBeExecuted`：`TakeDamage(处决伤害)`；
   - 其他情况（非濒死 / Boss）：`TakeDamage(刺击伤害 × 增伤系数)`；
7. **若锁定目标因本次伤害死亡**（死亡管线实际执行）→ 加血库 + 产出 PureBlood + 刷新 CD；否则不耗 CD 之外的额外资源、不刷新；
8. 真实时间约 0.5 秒到点，timeScale 恢复 1，解除输入锁定与无敌。

> 不存在多目标伤害：即使落点附近有其他敌人，也只有锁定目标受伤。

## 4. 与现有系统的对接要点

### 4.1 技能系统（SO + 效果组合）

现有 5 种效果（Move / Invincible / PlayAnimation / SetState / SpawnVFX）不够用，预计新增：

- **目标搜索效果/组件**：按半径 + 濒死优先级选敌，把"目标引用、位移方向、预定落点、出手时是否濒死"写入 EffectContext（需扩展上下文字段）；**无目标时技能不启动**（搜索结果作为释放前置条件，在 SkillManager 释放前判定）；
- **冲刺位移效果**：直接改位置（穿墙），按 **Time.unscaledDeltaTime** 驱动；不能依赖 FixedUpdate/MovePosition——物理步进在 0.2 倍速下会让冲刺视觉爬行；
- **单体伤害效果**：在刺击瞬间对 EffectContext 中的锁定目标调用 IDamageable.TakeDamage，区分处决/刺击伤害；
- **处决结算效果（袖剑专属部分）**：条件判定、血库回复、PureBlood 产出、CD 刷新；
- **慢动作控制**：进入时设 timeScale=0.2，结束（含任何中断）时必定恢复为 1；
- 无敌、SetState、播特效直接复用现有效果。

CD 刷新可复用 `SkillManager.AddCharge("袖剑")`（maxCharges=1 时一层即满）或 ResetCharges。

### 4.2 输入与键位

- 删除 [SkillManager.cs](SkillManager.cs) 中 `skill2Key`（Q → "技能2"），新增 F → "袖剑"；
- 无目标时按键无效且不耗 CD，需要把"目标搜索"放在消耗充能**之前**（或让袖剑技能提供一个 CanCast 前置检查钩子）；
- SkillData 资产名/技能名字符串定为 **"袖剑"**（血印的技能 CD 减免、最大层数加成均按此名匹配，改名有迁移成本，定了不要动）；
- 第二个 [SkillCooldownUI](../SkillCooldownUI.cs) 槽位的 skillName 改为 "袖剑"；
- 暂停页（PausePageController）增加袖剑状态判断，袖剑期间屏蔽 Esc 输入。

### 4.3 玩家状态与控制权（重要适配点）

- 当前 [Player.cs](../../Player.cs) 的 Update **每帧无条件**写入 `rb.velocity = 移动输入 × moveSpeed`，且**开火输入没有任何状态门控**；
- PlayerState 新增袖剑状态（如 `Executing`，CanMove=false），Player.Update 对该状态：
  - velocity 清零；
  - 屏蔽射击、换弹、切枪、翻滚/技能输入；
  - 跳过瞄准旋转（武器保持最后朝向）；
- SkillManager 的输入分支同样跳过。

### 4.4 慢动作的时间口径（重要适配点）

- **按下 F 当帧 timeScale=0.2**，袖剑协程/位移/计时一律用 **WaitForSecondsRealtime / Time.unscaledDeltaTime**，保证真实 0.5 秒走完；
- 敌人 AI、子弹、物理留在缩放时间 → 玩家相对世界表现为高速，实现"穿过弹幕"；
- 冲刺位移不用 Rigidbody2D.MovePosition（FixedUpdate 随 timeScale 变慢），改为每帧 transform 定位；
- 刺击特效 Animator 设为 `AnimatorUpdateMode.UnscaledTime`（参照 Boss 出场演出 GameUI.PlayBossShow 的做法）；
- **timeScale 恢复采用单一出口**：袖剑效果 OnEnd/Interrupt 中无条件恢复；Player.OnDestroy、场景加载等销毁路径也要兜底；
- 第一版袖剑期间屏蔽 Esc，不做 timeScale 嵌套栈。

### 4.5 无敌帧

- 直接复用 [InvincibleEffect.cs](InvincibleEffect.cs)：开始切到 Invincible 层（玩家及带碰撞体的子物体），结束恢复；
- 持续时间覆盖整个袖剑流程；现有近战 MakeDamage 与敌人子弹均已按 Invincible 层/物理碰撞跳过伤害，天然兼容；
- 中断/场景切换时 OnEnd 兜底恢复层。

### 4.6 伤害管线

- 现有统一入口 `PlayerUpgradeState.GetFinalDamageRatio(WeaponType)` 必须传武器类型，内部含武器独立系数与按武器聚合的血印系数，袖剑不能用；
- 第一版刺击伤害系数 = **全局增伤（GlobalDamageRatio）**，预留"技能增伤"乘区接口（未来新建 `GetFinalSkillDamageRatio()` 一类入口）；
- 处决伤害为独立的大数值常量（序列化，如 9999 量级），不吃任何加成；Boss 不会走处决分支；
- 伤害均通过 `IDamageable.TakeDamage(伤害, 命中方向)` 进入，自然触发现有受击特效/音效。

### 4.7 死亡管线、掉落与资源

- 袖剑击杀走 [EnemyBase.Death()](../../Enemy/EnemyBase.cs)：血印 NotifyUnitKilled、GenerateDrops（经验/金币/护盾；**敌人已不再掉落 DirtyBlood**）、移出房间、尸体、房间计数全部不变；
- 袖剑额外结算（以"本次袖剑伤害是否实际致死"为唯一条件）：
  - `BloodBank.Instance.AddBlood(处决回血量)`；
  - `Global.GeneratePureBlood(敌人, 敌人maxHealth × 袖剑吸血比例)` 产出吸血 PB；
  - 刷新袖剑 CD；
- 实现注意：TakeDamage 目前无返回值，结算需在伤害后确认"敌人是否真的进入死亡管线"（比对伤害后存活状态，或给 IDamageable 增加致死返回信息），避免无敌敌人/外部减伤导致"大伤害没打死却错误发奖励"；
- 回血量与吸血比例初期待定，全部序列化后靠实机调试（当前占位：回血 30、吸血 10%）；
- **Boss 的 DirtyBlood 固定掉落（5 个）保留**：普通敌人 5% 概率掉落已移除，DirtyBlood 产出收敛为 Boss + 宝箱 + 商店三条途径。

### 4.8 敌人改造

**可处决标志**

- EnemyBase（或 IDamageable）增加 `public bool canBeExecuted = true;`，BossBase 强制 false / Boss 预制体取消勾选；未来血印直接改写此标志。

**射击敌人转向限速**

- [ShootingEnemy.cs](../../Enemy/ShootingEnemy.cs) 增加序列化转向速度，FireBullet 中的 `UpdateRotate` 由瞬时转向改为限速转向，参照 [LaserEnemy.cs](../../Enemy/LaserEnemy.cs) 的 `Mathf.LerpAngle(current, target, rotationSpeed * dt / 180)`。

**近战敌人攻击前摇与距离字段**

- 现状：[MeleeEnemy.cs](../../Enemy/MeleeEnemy.cs) 的 FireSequence 是"`MakeDamage()` 当帧立即结算 → 等 AttackInterval"，且继承的 attackRange/chaseRange（12/10）是给游走射击型 AI 用的，MakeDamage 本身不做距离校验；
- 改造为：进入 Fire → **显示头顶红色"!"** → `WaitForSeconds(前摇≈0.3s，缩放时间)` → **重新检测距离与视线** → 在范围内才 MakeDamage，否则空挥 → 隐藏"!" → 等 AttackInterval → 回 Chase；
- MeleeEnemy 新增独立序列化字段（不复用 12/10）：
  - `meleeTriggerRange`：追击转攻击的触发距离；
  - `meleeDamageRange`：前摇结束时的伤害结算范围，**默认值略大于 meleeTriggerRange**（保证玩家持续移动时仍可能被命中，但袖剑拉开明显距离后必空挥）；
- 时间账：慢动作 0.2 倍下 0.3 秒前摇被拉长为 1.5 真实秒，袖剑 0.5 真实秒内必定安全；敌人未被处决时慢动作结束后前摇继续走完，玩家可能被反击——预期设计；
- 前摇 WaitForSeconds 用缩放时间（与敌人其他 AI 节奏一致）。

### 4.9 反馈与 UI

敌人头顶指示器（每个敌人预制体一个挂点，下挂两个默认隐藏的世界空间 TMP）：

- **"危"文本**：TakeDamage 导致血量首次跌破处决阈值时显示，Death 时隐藏；不限距离；文本内容 Inspector 可调；Boss 不显示；
- **红色"!"文本**：近战敌人前摇开始时显示，前摇结束（出手/空挥）时隐藏；
- 性能：房间敌人数量级下无明显开销；隐藏不渲染、静态文本不重建网格；显隐全部由事件（受击/前摇/死亡）驱动，不做每帧轮询；两个文本共享同一字体材质；

其他：

- 红色 AimMark：复制现有 AimMark 做红色变体，挂玩家身上，每帧定位到技能范围内最近的濒死敌人（唯一一个），无目标时隐藏；
- 冷却 UI：第二个技能图标槽绑定 "袖剑"，充能遮罩/数字逻辑零改动。

### 4.10 刺击特效与动画事件

- 玩家预制体下新增独立子物体 + 独立 Animator（不接入 Player Animator），updateMode = UnscaledTime，播放袖剑刺击帧动画特效；
- 第一版预留两个 trigger：处决 trigger、刺击 trigger（目标中途死亡的分支不触发）；
- 伤害时机：在刺击瞬间对锁定目标施加单体伤害（用动画事件卡命中帧，或由袖剑协程按真实时间计时，二选一，见第 9 节 Q2）；
- **动画事件接收者必须与 Animator 在同一 GameObject**：若特效 Animator 挂在子物体上，事件方法需写在该子物体的桥接组件上再转发，不能直接调父级 Player 的方法。

## 7. 风险与注意事项

1. **移动控制权冲突**：Player.Update 无条件写 velocity，是冲刺位移最容易出 bug 的地方，需先加状态门控；
2. **timeScale 恢复责任**：正常结束、目标死亡提前结束、被打断、场景切换、玩家死亡——每条退出路径都必须恢复 timeScale，建议单一出口（OnSkillEnd/Interrupt 兜底）；
3. **物理在慢动作下变慢**：FixedUpdate 随 timeScale 缩放，依赖 MovePosition/碰撞体的位移会爬行，袖剑冲刺用 unscaledDeltaTime 直接定位；
4. **穿墙位移可能穿过厚墙/房门**：限定当前房间选敌 + 落点墙体修正双重保险；直接改位置的位移方式无视墙体碰撞体；
5. **目标引用失效**：冲刺途中敌人被流弹击杀走"立即结束+退款"分支；目标被房间清理直接销毁时按 null 同样处理；
6. **奖励误判**：无敌敌人/未来减伤可能让大伤害不致死，发奖励前必须确认死亡管线实际执行；
7. **无目标按键反馈**：F 无目标时完全无表现，玩家可能误以为按键失灵。第一版至少打一条 debug 日志；正式版可考虑在冷却图标上给灰态反馈（本期可选）；
8. **动画事件挂载点**：事件方法必须在 Animator 所在 GameObject 的组件上，注意桥接；
9. **音效**：游戏主要走 FMOD，timeScale 一般不影响 FMOD 事件音高，实现时需验证慢动作期间音效表现；
10. **字符串耦合**：技能名 "袖剑" 同时被 SkillData、输入、UI、血印匹配引用，重命名需全局同步。
